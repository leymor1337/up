# Круглое счастье — информационная система сети ресторанов (1С:Предприятие 8.5)

Учебная практика ПМ.02 «Осуществление интеграции программных модулей», ГБПОУ РХ ХПК, группа ИС(ТП)-41, Круглов В. А.

## Состав репозитория
- `src/` — исходные файлы конфигурации (Конфигуратор → Конфигурация → Выгрузить конфигурацию в файлы)
- `VA/features/` — сценарии Vanessa Automation (Gherkin)
- `backup/KS_backup_2026-11-06_17-06.dt` — резервная копия информационной базы
- `docs/` — отчёт по практике, тестовые наборы, тестовый документ, отчёт об отладке, словарь данных, ER-диаграмма

## Развёртывание
1. Установить платформу «1С:Предприятие» 8.5.
2. Создать пустую информационную базу и в конфигураторе выполнить «Администрирование → Загрузить информационную базу», выбрать файл `.dt`.
3. Войти под пользователем «Администратор» (пароль задаётся при внедрении).

## Тесты Vanessa Automation
1. Открыть `vanessa-automation-single.epf` (релиз 1.2.043.28, https://github.com/Pr-Mex/vanessa-automation/releases) через «Файл → Открыть».
2. Загрузить feature-файл из `VA/features` и нажать «Выполнить сценарии».
3. Для UI-сценариев запустить клиент тестирования: `1cv8c.exe ENTERPRISE /F"<путь к базе>" /TESTCLIENT -TPort 48050`.
